# PULSE AI frontend

Vite + React + TypeScript. See the repository README one level up for setup, scripts and architecture.

- `npm run dev` starts the dev server on :5173 (proxies /api to the backend on :8000)
- `npm run typecheck`, `npm test`, `npm run build`, `npm run e2e`
- `src/pulse/` is the PULSE AI brand kit (see docs/asset-integration.md)
